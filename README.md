# English Quiz Master

Buatkan game quiz interaktif untuk bahasa inggris dengan topik pada screenshot. Jumlah soal ada 30. pilihan ganda a,b,c,d dan 2 soal uraian. Waktu pengerjaan soal 20 menit untuk 30 soal pilihan ganda dan 2 soal uraian. Sistem penilaian pilihan ganda: benar +4, salah -1 dan tidak diisi 0, Sistem penilaian uraian: jika benar mendapatkan poin maksimal 10 untuk tiap soal uraian.
